- **Validation Set (`unsloth_sft_val.jsonl`):** **222 samples** across the same 40 tasks.

### Token Length Distribution
Measured from `estimated_tokens` per trajectory:
- **Min:** 665 tokens
- **Median:** 1,162 tokens
- **90th Percentile (P90):** 1,686 tokens
- **Max:** 2,822 tokens

> **Crucial Finding on Sequence Length:** 100% of the dataset fits comfortably under **3,072 tokens**. No sample requires 6,144 or 16,384 tokens. This is a massive operational win for VRAM consumption on a single 24GB L4 GPU.

## 3. Critical Findings & The Data Sufficiency Question

### Is 885 samples enough for LoRA training?
**YES, quantitatively.**
- In parameter-efficient fine-tuning (PEFT/LoRA) on attention layers (`q_proj`, `v_proj`, `o_proj`, Rank 8, Alpha 16), the trainable parameter count is only ~15M out of 31B ($<0.05\%$).
- For instruction and tool-calling alignment, literature (LIMA, Toolformer, SWE-agent SFT) demonstrates that **500 to 1,200 curated, high-density trajectories** is the optimal training regime. Training on $>3,000$ samples with small rank causes catastrophic overfitting and degenerates general reasoning.

### What are the structural gaps in the current data?
1. **Zero `run_command` Representation:**
   Because the dataset was extracted from `results/run_B39` and `run_B40` (which ran a 5-tool configuration without `run_command`), the model will NOT be taught how to execute `python /tmp/repro.py` or run `pytest -k`.
   - **Risk:** The trained adapter will not naturally use the shell execution feedback loop that makes the 0.12 baseline work.
2. **Heavy Skew toward `run_skill_script` (64.3%):**
   The trajectories heavily teach calling pre-installed skills (`fast-grep`, `code-map`, `repro-check`, `test-gate`). If we deploy with skills enabled, this is beneficial. But it under-trains direct `edit_file` surgical syntax (only 66 edit turns).
3. **Task Breadth (40 tasks vs 129 total):**
   The dataset covers 40 tasks. The remaining 89 tasks from `tasks.jsonl` are unrepresented in the training trajectories.
4. **Teacher Lineage (Imitation Learning):**
   The trajectories were generated by LiteRouter proxy (`stealth/space-bunny-alpha`). This makes our training an explicit **Teacher-Student Knowledge Distillation** (distilling a stronger model's successful SWE paths into Gemma 31B).
